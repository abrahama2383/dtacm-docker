Dynatrace ACM Workshop — Dockerized Topology

Single VM · Docker Compose · Jenkins + AWX + SockShop (converted from GKE/AKS)

CI/CD control plane

  • • Jenkins controller image bundles docker CLI + maven
  • • Deploys via mounted docker.sock — docker compose up replaces kubectl apply
  • • JMeter runs as a per-run container on sockshop-dev_net, hitting carts:80
  • • Pipeline: dev → load test → quality gate → prod

Self-healing (AWX / Ansible)

  • • AWX 17.1.0 via its Docker-Compose installer (no k8s)
  • • Dynatrace problem → remediation job template
  • • Playbooks set carts /promotion back to 0% (rollback)
  • • Reaches prod carts on host-published :8091

SockShop stages

  • • Two Compose projects = the old dev / production namespaces
  • • Each on its own network → identical service names, no clash
  • • nginx gateway = the k8s Service (port 80 → 8080)
  • • dev UI :8079 · prod UI :8081

Monitoring & access

  • • One host OneAgent replaces OneAgent Operator + ActiveGate VM
  • • Auto-instruments every container on the VM
  • • All UIs reachable on the VM's public IP + port
  • • ⚠ change default creds & firewall to your IP before exposing
